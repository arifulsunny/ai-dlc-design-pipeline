# Design Implementation Audit

## Purpose

This file validates whether the implemented product matches the approved design artifacts.

## Audit Inputs

- Approved screen specs
- Component contracts
- Interaction spec
- State model
- Design tokens
- Accessibility checklist
- Frontend and backend handoff
- Acceptance criteria
- Implemented UI or pull request
