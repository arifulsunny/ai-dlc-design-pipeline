# Version History

## Purpose

This file tracks design artifact versions across the pipeline.

## Versioning Rules

| Version Type | Meaning | Example |
|---|---|---|
| `v1.0.0` | Initial approved design | First complete pipeline |
| `v1.1.0` | Minor UX improvement | Improved state copy |
| `v1.2.0` | New screen, flow, or feature added | Added onboarding flow |
| `v2.0.0` | Major redesign or flow-level change | Reworked navigation model |

## Version Update Checklist

- [ ] Change log updated.
- [ ] DDR updated when needed.
- [ ] Affected files listed.
- [ ] Related issue or PR linked.
- [ ] Rollback note added when needed.
- [ ] Release design notes updated for user-visible changes.

## Quality Gate

- Version history must match the latest design change log.
- Version status must be clear before release.
